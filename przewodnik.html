Wczytywanie dostępnych głosów…

01. Pobierz instalator

Pobierz DiskRecoveryPRO_Setup.exe z oficjalnego wydania. Sprawdź wersję i sumę SHA-256, jeśli została opublikowana. Nie uruchamiaj instalatora z nieznanego portalu.

Oficjalne wydanie

02. Zainstaluj w Windows

Uruchom EXE, sprawdź wydawcę, zaakceptuj UAC tylko dla zaufanej wersji i dokończ instalację. Nie wyłączaj antywirusa, gdy plik zostanie zablokowany.

03. Pierwsze uruchomienie

Uruchom program z menu Start. Poczekaj, aż wykryje nośniki. Operacje wymagające administratora potwierdzaj tylko wtedy, gdy rozumiesz, co wykonują.

04. FREE, licencja i konto właściciela

FREE jest okresem ograniczonym. Zalogowanie właściciela odblokowuje funkcje administracyjne tej sesji, ale samo w sobie nie jest zakupioną licencją. Licencję klienta wczytaj plikiem .drplic albo pełnym kodem DRP1:.

Plany i aktywacja

05. Wybierz źródło

Wybierz dysk, wolumin, pendrive albo kartę SD, z której chcesz odzyskać pliki. Sprawdź model, literę woluminu i pojemność.

06. Wybierz inny nośnik docelowy

Cel musi być innym fizycznym dyskiem niż źródło. Nie zapisuj odzyskiwanych plików na źródle, bo możesz nadpisać utracone dane.

07. Szybkie skanowanie

Rozpocznij szybkie skanowanie, jeśli system plików jest dostępny i szukasz niedawno usuniętych plików. Nie wyjmuj nośnika podczas odczytu.

08. Pełne skanowanie / RAW

Pełne skanowanie trwa dłużej. Jeśli dysk klika, znika lub zgłasza błędy odczytu, ogranicz dalsze testy i najpierw wykonaj obraz sektorowy na inny nośnik.

09. Sprawdź znalezione pliki

Użyj podglądu, jeśli jest dostępny. Nazwa lub nagłówek pliku nie gwarantuje, że cała treść jest czytelna. Zaznacz tylko potrzebne pliki.

10. Odzyskaj i sprawdź pliki

Zapisz dane na osobnym dysku. Po zakończeniu otwórz kilka plików, sprawdź rozmiary i zapisz raport. Liczba znalezionych pozycji nie gwarantuje poprawności odzysku.

11. Diagnostyka HDD / SSD / USB / SD

W górnym pasku wybierz „Diagnoza / naprawa nośnika”. Odśwież listę, wybierz urządzenie i uruchom diagnozę. Nieznane mapowanie dysku fizycznego blokuje przypisywanie SMART.

12. SMART i zużycie

Jeśli kontroler udostępnia dane, sprawdź temperaturę, wear, godziny pracy i błędy. Czytnik USB/SD może ukrywać SMART. Brak danych nie dowodzi sprawności.

13. Ryzyko awarii

Wskaźnik ryzyka jest heurystyką, nie prawdopodobieństwem 50/50. Program nie może wiarygodnie obiecać konkretnego dnia awarii. Przy alarmach najpierw zabezpiecz dane.

14. Naprawa systemu plików

CHKDSK /f zmienia metadane systemu plików. Uruchamiaj go dopiero po diagnozie i potwierdzeniu kopii. Nie używaj /f ani formatowania na RAW lub niepoznanym źródle ważnych danych.

15. Test prędkości dysku

Wybierz rozmiar próbki i miejsce testu. Test zapisuje plik tymczasowy, nie sektory urządzenia. Nie uruchamiaj go na jedynej kopii danych, które odzyskujesz.

16. RAM, GPU i VRAM

Uruchom dostępne testy i zapisz wyniki. Krótki test próbki nie potwierdza sprawności każdej komórki RAM/VRAM ani stabilności w każdym obciążeniu.

17. BSOD / Minidump

Wybierz zrzut awarii. Pełna analiza stosu wymaga WinDbg/CDB i symboli. MODULE_NAME lub IMAGE_NAME to trop, a nie pewny dowód winy sterownika.

18. Naprawa Windows

Przed DISM/SFC, naprawą rozruchu lub zmianą sterowników zabezpiecz dane. Wykonuj jeden krok, sprawdź wynik, a potem powtórz diagnozę. Zmiany wymagają zgody.

19. Zakup i aktywacja

Wybierz plan SumUp i zachowaj potwierdzenie. Po ręcznej weryfikacji otrzymasz .drplic lub DRP1:. W aplikacji wybierz „WCZYTAJ PLIK” albo „WPISZ KOD”. Uruchom program ponownie i sprawdź, że status licencji nadal jest aktywny.

Kup / aktywuj

20. Aktualizacje i zgłoszenie błędu

Sprawdź wydanie, poczekaj na pobranie i weryfikację SHA-256, następnie zatwierdź instalator/UAC. Jeśli coś nie działa, zapisz raport i zgłoś problem właścicielowi; logi wysyłaj tylko za zgodą.
